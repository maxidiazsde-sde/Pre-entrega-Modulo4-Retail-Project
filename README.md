# Pre-entrega Módulo 4 - Retail Project

## Curso
Data Science - SQL (Coderhouse)

## Objetivo

Desarrollar consultas multicapa para análisis de negocio utilizando:

- JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- Funciones de agregación
- CTE (WITH)
- ROW_NUMBER()

## Consultas realizadas

### 1. Rentabilidad por categoría
Calcula las unidades vendidas y el ingreso total por categoría.

### 2. Clientes sin compras
Identifica los clientes registrados que aún no realizaron compras.

### 3. Top de compras por cliente
Obtiene el producto más comprado por cada cliente y la fecha de su última compra.
